## 1. Resumen Ejecutivo y Metodología de Trazabilidad

Esta matriz documenta la superficie completa de usuario y de integración del frontend de EspaciGo, estableciendo la correlación verificable entre:
1. **Rutas URL del App Router** (Marketplace, Identidad, Cuenta, Anfitrión, Reservas, Administración, Infraestructura/BFF).
2. **Capacidades funcionales y reglas de negocio** (Validaciones de dominio, accesibilidad WCAG 2.1 AA / Axe, responsividad móvil y desktop).
3. **Contratos y Endpoints OpenAPI asociados** (Operaciones declaradas en `planning/openapi.yaml` y gestionadas por el Gateway Same-Origin en `/api/backend/[...path]`).
4. **Pruebas Automatizadas de Verificación** (Suites unitarias de dominio `tooling/*.test.mjs`, suites E2E Playwright controladas y suites nativas contra la API Go en loopback `127.0.0.1:18082`).

Todas las operaciones que mutan estado utilizan `Idempotency-Key` UUIDv4 inmutable. Toda moneda se calcula de forma exacta en enteros CLP sin redondeo en coma flotante. Ningún secreto, credencial sensible ni token Bearer es almacenado en localStorage, sessionStorage ni cookies accesibles por script.

## 3. Resumen de Métricas de Cobertura y Verificación

- **Rutas del App Router cubiertas:** 36 rutas productivas e infraestructura.
- **Operaciones OpenAPI mapeadas:** 179 operaciones OpenAPI integradas a través del Gateway Same-Origin.
- **Suites de Pruebas Unitarias y de Dominio:** 54 pruebas aprobadas en Node.js test runner (`tooling/*.test.mjs`), cubriendo CLP exacto, validaciones de teléfono, RBAC, concurrencia optimista, tokens de fragmento y contratos.
- **Suites E2E Playwright:** 64 pruebas aprobadas en modo controlado (incluyendo auditorías Axe de accesibilidad sin violaciones en viewports desktop `1365×900` y mobile `390×844`, y sin desbordamiento horizontal). 45 pruebas adicionales configuradas para verificación nativa loopback con API Go y base de datos de ensayo.
- **Aislamiento de Red:** 100% verificado (`scripts/verify-network-isolation.sh`). El contenedor y la aplicación frontend se comunican exclusivamente mediante la red `api`; la red `data` y la base de datos PostgreSQL permanecen completamente inaccesibles e invisibles para la capa web.
