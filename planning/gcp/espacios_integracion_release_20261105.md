La propuesta source-only recomienda mantener carga/descarga/revisión en el API privado existente, separar el consumidor de jobs PostgreSQL en un worker continuo y aislar ClamAV detrás de HTTP privado autenticado con IAM. 1. **Storage cifrado y eliminación:** implementar las interfaces documentales de identidad/espacio sobre un store de objetos privado, conservando AES-GCM, AAD ligado al ámbito autoritativo, límites, creación inmutable y ausencia de URLs públicas.
