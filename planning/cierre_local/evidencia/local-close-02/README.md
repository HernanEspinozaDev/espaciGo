## Límites y decisión

El flujo principal quedó integrado en un E2E real Angular→Go→PostgreSQL. Las mutaciones posteriores al contrato (incluida la firma del arrendatario) se hicieron contra endpoints Go desde Playwright, no pulsando cada acción de Angular. La UI sí se usó para iniciar y revisar el ciclo, y para leer estado/historial/comprobante. El test nuevo no sustituye la suite histórica de 18 pruebas E2E, que se ejecutó sobre el SHA base indicado en su propia evidencia y no se volvió a ejecutar completa en este corte; la corrida actual focalizada pasó 1/1.

La restauración DOCKER-03 se verificó con stacks, directorios y volúmenes separados, pero es evidencia de recuperación técnica del ensayo; no equivale a una aceptación funcional del producto ni a restore de un sistema publicado. La demo retenida se actualizó y queda identificada abajo. No se usaron proveedores reales, fondos/personas reales ni GCP. El usuario aceptó el cierre local sintético documentado el 2026-10-14; #267/#269 se cerraron como completadas por la evidencia nueva de #310 y esa decisión. No se recuperó el volumen original DOCKER-02 ni se completó la reserva de 2026-10-11. Esta aceptación no es de producto público ni de GCP.
